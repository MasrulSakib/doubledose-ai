# DoubleDose AI — User Guide

## 1. Access the Application

Open the deployed application:

**https://doubledose-ai.vercel.app**

DoubleDose AI helps users search medicine products, review medicine candidates extracted from packaging images, and compare recorded active ingredients.

## 2. Search for a Medicine

1. Open the medicine search interface.
2. Enter a medicine brand name or another supported search term.
3. Review the returned medicine records.
4. Select the intended product.

![Medicine search interface](images/medicine-search.png)

## 3. Upload a Medicine Image

1. Open the OCR or medicine-image upload interface.
2. Select a clear image of the medicine strip or box.
3. Wait for the OCR service to extract text.
4. Review the extracted text for spelling errors, missing strengths, or unrelated packaging text.
5. Correct the text if necessary and request matching candidates.

OCR results can be inaccurate. Use the actual packaging to verify the medicine name and strength.

![OCR candidate matching](images/ocr-candidates.png)

## 4. Review and Confirm Candidates

1. Examine the suggested medicine candidates.
2. Compare their brand names, generic ingredients, strengths, and dosage forms when available.
3. Select the candidate that matches the packaging.
4. Do not assume that the highest similarity score proves the product is correct.

If the correct medicine is not listed, try correcting the OCR text or searching manually.

## 5. Compare Medicines

1. Select the medicines you want to compare, within the application's selection limit.
2. Run the ingredient comparison.
3. Review shared recorded active ingredients and any warnings.
4. Read incomplete-data notices carefully.

![Ingredient comparison results](images/ingredient-overlap.png)

The comparison depends on the ingredient information available in the database. Missing or incomplete ingredient mappings may cause potential overlaps to be missed.

## 6. Read the AI Explanation

Review the explanation generated by the application after the comparison, where available.

![AI-generated explanation](images/ai-explanation.png)

AI-generated text can contain inaccurate or incomplete information. Treat it as supplementary information, not as verified medical advice.

## 7. Understanding Results

- **Shared ingredient found:** The selected products share an ingredient recorded in the database. Ask a pharmacist or physician before combining them.
- **No shared ingredient found:** No shared ingredient was identified in the available records. This does not mean the combination is safe.
- **Incomplete-data warning:** Some ingredient information is missing, so the comparison may be incomplete.
- **Medicine candidate:** A possible match returned by the matching system. Confirm it against the actual package.

Therapeutic-class warnings, when displayed, are separate from exact ingredient-overlap results.

## 8. Safety and Responsible Use

DoubleDose AI is an informational and educational prototype. It does not diagnose conditions, prescribe medication, provide individualized dosing advice, or comprehensively detect drug interactions.

Always verify medicine names and strengths against the actual packaging. Consult a qualified pharmacist or physician before combining medicines, changing treatment, or making medication decisions.
